3. Operational Troubleshooting & Runbook

  • Port Conflict (8000 in use): Launch with custom port: python -m uvicorn app.main:app --port 8080 --reload.
  • Database Reset: Delete monitoring.db and restart the application; the schema and initial seed data will regenerate automatically.
  • Connecting Prometheus & Grafana: Point your Prometheus scrape configuration to http://localhost:8000/metrics with a 5s scrape interval.
  • Enabling Live Gemini AI: Set the GEMINI_API_KEY environment variable in your terminal before launching.
